# Sales Data Analysis & Transformation Using Power BI

A data preparation project in which sales datasets were extracted, cleaned and transformed using Power Query to produce curated, analysis-ready data for business reporting and visualization.

## Project Overview
- Performed extract-transform-load (ETL) steps on sales datasets using Power Query.
- Identified and corrected data quality issues using Power Query:
  - Blank values
  - Duplicate records
  - Incorrect data types
- Prepared curated, analysis-ready datasets to support business reporting and visualization.

## Tools Used
- Power BI
- Power Query
