# Data dictionary

| Column | Meaning | Suggested data type |
|---|---|---|
| OrderID | Unique order identifier | Text |
| OrderDate | Date the order was placed | Date |
| CustomerID | Sample customer identifier | Text |
| Region | Sales region | Text |
| Category | Product category | Text |
| Product | Product name | Text |
| Quantity | Number of units sold | Whole number |
| UnitPrice | Price per unit | Fixed decimal / Currency |
| Sales | Quantity multiplied by unit price | Fixed decimal / Currency |

**Dataset note:** All records are synthetic and intended only for learning and portfolio demonstration.
